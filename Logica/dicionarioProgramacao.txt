Operadores
// "=" -> Atribuição, atribui um valor a algo
// "==" -> Comparação, compara dois valores
// ">" -> Maior, verifica se é maior
// "<" -> Menor, verifica se é menor
// ">=" -> Maior Igual, Verifica se o valor é maior ou igual a outro
// "<=" -> Menor Igual, verifica se o valor é menor ou igual a outro

Condicionais
// if(condicao){acao a ser executada} -> Depende da condição para executar o código.
// else if(condicao){acao a ser executada} -> Permite mais de duas condições, mas depende de alguma das condições para não cair no else.
// else{acao a ser executada} -> Caso nenhuma condicao(if) for atendida, ele executa esse codigo.

Casos Dependentes
// Switch(o que vai receber){
case "valor esperado": 
    o que executar caso for esse valor
    break -> para parar 
default:
    o que executar caso não atender nenhum valor
} 
    Utilizado quando tem Varios casos

Input
    <input type="tipo do input"> -> Caixa para receber algo  
    <input type="text"> -> Recebe qualquer valor que seja texto
    <input type="number"> -> Recebe qualquer valor que seja número
    <input type="date"> -> Recebe valor de datas
    <input type="datetime-local"> -> Recebe valores de datas com horário
    <input type="password"> -> Recebe valores como senha, e não mostra o que foi digitado, pela privacidade
    <input type="color"> -> Recebe cor
    <input type="checkbox"> -> Recebe uma seleção
    <input type="image"> -> Recebe uma imagem
    <input type="file"> -> Recebe um arquivo
    <input type="reset"> -> Reseta 
    <input type="submit"> -> Envia
    <input type="button"> -> Botão
    <input type="email"> -> Recebe um email
